## 📋 Overview

This project was developed as part of the **PIDEV – 4rd Year Engineering Program** at **Esprit School of Engineering** (Academic Year 2025–2026).

yBrainy Forum is an intelligent, AI-powered community platform designed specifically for e-learning environments. It goes beyond traditional discussion boards by integrating machine learning for auto-categorization, toxicity detection, smart recommendations, and a comprehensive gamification system that motivates student engagement.

The platform is built using a **microservices architecture** with Angular for the frontend and Spring Boot for the backend, demonstrating enterprise-level software engineering practices.

---

## ✨ Key Features

### 🤖 AI-Powered Intelligence
- **Auto-Categorization**: ML model automatically classifies threads into 20+ categories with 85%+ accuracy
- **Toxicity Detection**: Real-time content moderation using NLP to maintain a safe learning environment
- **Smart Recommendations**: Personalized thread feed using collaborative filtering and content-based algorithms
- **Auto-Documentation**: Automatically fetches and links official documentation when technical topics are mentioned

### 🎮 Gamification System
- **XP & Leveling**: 8-level progression system (Newcomer → Legend) with privilege unlocks
- **Badges & Achievements**: Earn badges for expertise, streaks, and contributions
- **Leaderboard**: Weekly/monthly/all-time rankings to motivate participation
- **Best Answer System**: Stack Overflow-style answer validation with XP rewards

### 💬 Advanced Forum Features
- **Rich Text Editor**: Markdown support, code highlighting, LaTeX equations, embedded media
- **Multi-Reaction System**: 8 contextual reactions beyond simple upvote/downvote
- **Thread View Counter**: Real-time view tracking with Redis buffering
- **Nested Replies**: Up to 3 levels of comment threading
- **Full-Text Search**: MySQL FULLTEXT search with semantic capabilities

### 🔔 Real-Time Features
- **Live Notifications**: WebSocket-powered instant notifications for replies, mentions, badges
- **Activity Feed**: Real-time updates on thread activity
- **Online Presence**: See who's currently reading the same thread


## 🛠 Tech Stack

### Frontend
- **Framework**: Angular 17 (Standalone Components)
- **Language**: TypeScript 5.x
- **State Management**: NgRx Signals
- **UI Library**: Angular Material + Tailwind CSS
- **HTTP Client**: RxJS-based reactive programming
- **Real-time**: WebSocket (STOMP)

### Backend
- **Framework**: Spring Boot 3.2.x
- **Language**: Java 21
- **Architecture**: Microservices
- **API Gateway**: Spring Cloud Gateway
- **Service Discovery**: Eureka
- **Security**: Spring Security + JWT (RS256)
- **ORM**: Spring Data JPA + Hibernate

### Databases & Caching
- **Primary Database**: MySQL 8.0+
- **Cache**: Redis 7.x
- **Message Broker**: Apache Kafka 3.x

### DevOps & Tools
- **Build Tool**: Maven
- **Database Migration**: Flyway
- **API Documentation**: Springdoc OpenAPI (Swagger)
- **Testing**: JUnit 5, Mockito, Testcontainers
- **Monitoring**: Spring Actuator + Prometheus
